## Результат и границы

Новая форма включает readableBranch=true. После завершения уточнений отдельный вызов LLM предлагает только английский slug; код добавляет выбранный тип feat/fix/test/docs и первые 8 символов UUID. Например feat/habit-categories-a1b2c3d4. На итоговом шаге человек видит полное имя и может исправить смысловую часть. Без ИИ имя вводится вручную. Вопросы, описание и внешние действия сохраняют отдельные контракты. Существующие ветки не переименовываются; прежние API-клиенты продолжают прежнее именование. Commit/push/публичная выкладка не входят в запрос.

## Критерии

- ИИ предлагает имя только после итогового черновика; до подтверждения GitHub ref не создаётся.
- Поле имени редактируется; сервер проверяет 3–60 lowercase ASCII букв/цифр/одиночных дефисов, первая буква, без префикса, слеша и ID.
- Тип/ID добавляет код; запрещённые имена не достигают записи GitHub.
- Неудача предложения не уничтожает черновик, ручной ввод доступен.
- Занятое имя не перезаписывается; повтор подтверждения сохраняет исходную ветку.
- Старые карточки и новая форма без ИИ совместимы.
