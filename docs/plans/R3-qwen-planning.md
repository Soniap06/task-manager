# R3: оформление карточки и уточняющие вопросы

Статус: реализовано и проверено локально. Владелец: Codex. Review: команда проекта.
Ветка и база: `codex/r3-qwen-planning`, `b1f171e`. Продолжение существующей задачи R3 по новому согласованному объёму, без новой дублирующей ветки.
Требования: варианты 1 и 3 — оформление карточки и помощь в уточнении требований.

## Результат и границы

Qwen предлагает только заголовок, краткое описание и от нуля до трёх уточняющих вопросов. Она не составляет технический план, не извлекает критерии и не выбирает имя ветки. Пользователь выбирает тип задачи, проверяет/редактирует черновик, отвечает на вопросы и явно подтверждает создание ветки. Исходные требования и ответы сохраняются отдельно от описания. При ошибке модели и в режиме «Без ИИ» доступно ручное оформление.

Исходники рабочего репозитория модель не читает; выполнение задач, спринты и review не реализуются. Ранее выявленные ошибки CSS-планов и миграций стали основанием сокращения ответственности модели. История прежней настройки сохранена локально в .data/backups/r3-before-simplification.

## Решения

- Контракт ИИ: `{title, description, questions}`. Строгая валидация типов, длины, неизвестных полей и повторов вопросов. Ключ uniqueItems не отправляется: текущий MLX-движок его не поддерживает.
- `lib/task-draft.js`: контракт и формирование веток кодом. Типы feature/fix/tests/docs отображаются в feat/fix/chore; имя `prefix/task-<uuid>`. Модель не управляет ref или репозиторием.
- `lib/tasks.js`: draft_ready / clarification_required / generation_error до подтверждения. `POST /api/tasks/:id/confirm` сохраняет проверенные поля и ответы перед внешней операцией. Повтор не создаёт новую ветку. Сохранены снимки проекта/базы и восстановление GitHub-операций. Прежние карточки/ветки не перезаписываются.
- UI: тип задачи, «Без ИИ», редактор черновика в диалоге карточки, исходный запрос, вопросы и ответы. Подробности не выводятся на доске.
- Подключение по-прежнему в локальном ai.config.json; ключ только в .env. Setup не перезаписывает личные файлы. Qwen3.5-9B, контекст 4096, parallel 1; локальный профиль сохранён.

## Критерии и прогресс

- [x] Новый ограниченный контракт, исходный запрос хранится неизменно.
- [x] Ветка формируется кодом только после подтверждения, вопросы требуют ответов.
- [x] Ручная работа при недоступной модели и отдельный режим без ИИ.
- [x] Автоматические проверки повторов, ошибок, подтверждения и изоляции проектов.
- [x] Ручная проверка обычного/узкого экрана и реальной Qwen без GitHub-записей.
- [x] Документация соответствует окончательному сценарию.

## Проверки и передача

Пройдены npm run check (33 JS-файла и ресурсы HTML), npm test (95/95) и git diff --check. Тесты проверяют отсутствие веток до подтверждения, ручной режим, ошибки модели/сохранения, повторы, проектные снимки, устаревшие ответы другой вкладки и совместимость старых карточек. В автоматических и браузерных проверках GitHub заменяется заглушкой. Реальные прогоны модели вызывают только /api/ai/generate-task или общий клиент, не сохраняют карточек/веток. Коммит/push пока не выполнялись.


### Реальные и браузерные проверки

После уточнения prompt проверены шесть реальных черновиков Qwen3.5-9B: 6/6 прошли контракт, 18,7–34,6 с. Удаление сохранило 404 и оба теста, CSS сохранил размеры и запрет менять JS/backend, миграция сохранила неотрицательность, целочисленность, остановку без изменений и откат. Запрос с попыткой сменить формат сохранил JSON без branch и не включил постороннюю команду в описание. Поиск получил вопрос о префиксе/подстроке.

Смысловые ограничения остаются: поиск получил лишнее упоминание тестов; README — ненужные вопросы о командах из package.json и зависимостях; миграция — вопрос об уже заданном поведении отрицательных значений. Это не безупречная семантическая проверка. Пользователь может отредактировать описание и указать в ответе, что вопрос не относится к задаче. Исходный текст остаётся самостоятельным источником требований, предположения модели не выполняются автоматически.

Фактический POST /api/ai/generate-task после перезапуска Task Manager: HTTP 200 за 24,1 с, только title/description/questions, CSS без лишних вопросов. Хеш рабочего tasks.json совпал до/после этого запроса и всей серии. Рабочие тестовые карточки и GitHub-ветки не создавались.

Браузер: изолированный порт 3001, отдельное временное хранилище и заглушки GitHub/ИИ. Проверены пустой ответ (подтверждение заблокировано), редактирование, сохранение вопроса/ответа и исходного текста, режим «Без ИИ» с chore, ошибка ИИ с ручным завершением, создание клавишей Enter, подтверждение с draftRevision, перенос и восстановление после перезагрузки. Проверены ширины 320, 375 и 1280 px; временная ширина сброшена. Рабочие прежние карточки сохраняются.

Изолированный стенд после проверки останавливается; рабочее приложение остаётся на порту 3000. Изменения в существующей ветке R3 пока не закоммичены и не опубликованы. Автоматические проверки успешны; полную смысловую надёжность Qwen не заявляем. Следующий шаг при публикации — review diff и явное решение по оставшимся ограничениям качества модели.
