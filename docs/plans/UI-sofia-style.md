## Результат и границы

Доска и проекты используют существующий визуальный слой public/css/style.css: тёплый фон, бордовые акценты, белые колонки и розовые карточки, верхнюю навигацию. Сохраняются все рабочие элементы, отдельная страница репозиториев, черновик/вопросы/подтверждение, поиск, переносы и доступность. Функции GitHub/LLM и рабочие данные не меняются.

## Решения

Общий CSS подключается перед небольшим слоем адаптации в корневом style.css. Навигация доступна через нативный details/summary без нового JS-клиента. Сохраняются ID элементов существующих контроллеров. Счётчики колонок показывают число видимых карточек, обновляясь при поиске и переносе. На странице проектов подключение и выбранный проект оформляются отдельными панелями.
