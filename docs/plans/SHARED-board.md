# SHARED: одна доска через закрытую сеть

Статус: программная часть подготовлена; Tailscale Serve включён, HTTPS и вход проверены на компьютере Карины; проверка с компьютера Софии ожидается. Владелец: Codex. Review: Карина и София.
Ветка: codex/shared-board-tailscale; база 44ca44a (также включена в upstream/main ad84525).
Требования: работать на двух компьютерах из разных сетей с одними карточками.

## Результат и границы

Один Node.js-процесс и DATA_DIR на компьютере Карины; оба браузера открывают HTTPS-адрес Tailscale Serve. Ключ GitHub и LM Studio остаются у Карины. Новый режим включается явно через SHARED_ORIGIN; локальный запуск не меняется. Перенос хранилища, регистрация, роли и полноценное одновременное редактирование не входят в задачу; пока используется общий демонстрационный логин.

## Решения

Не открывать Node.js на 0.0.0.0: только loopback и закрытый HTTPS-прокси Tailscale Serve. В shared-режиме требуются полный серверный вход и точный https://hostname.ts.net без пути. Cookie Secure; мутации проверяют канонический Origin. Заголовки identity/forwarded не используются для авторизации. Карточки обновляются каждые 5 секунд без фоновой записи, с пропуском скрытой вкладки, занятой доски и открытого редактора; отставшие ответы из других проектов отбрасываются существующей проверкой версии.

## Критерии и шаги

- [x] Shared-режим отвергает неверный адрес и незавершённую настройку входа.
- [x] Только разрешённый Host/Origin, обязательная сессия и Secure-cookie; локальные сценарии сохранены.
- [x] Два клиента читают одну карточку и видят смену статуса; polling не стирает редактор и не создаёт внешние операции.
- [x] Проверки, документация и инструкция подключения/отключения Tailscale.

## Проверки и передача

HTTP: две сессии читают/переносят одну карточку без GitHub-записи, неверные Host/Origin/пустой Origin отклоняются, cookie Secure, незавершённая авторизация запрещает старт. Браузерная логика: фоновая загрузка изменений, пропуск открытого редактора и отклонение фонового ответа, пришедшего после открытия редактора; прежние сценарии сохранены. Это программные проверки, не реальный VPN-сеанс. Результаты отдельного реального запуска приведены ниже. Проверка с компьютера Софии требует участия команды; автоматические проверки не подтверждают её пользовательский сценарий.

## Реальный запуск 22 октября

Создана резервная копия JSON/SQLite после остановки прежнего сервера. Новый процесс запущен из отдельного worktree с абсолютным DATA_DIR прежней доски; личные файлы не входят в Git. Tailscale Serve работает в фоне, только внутри закрытой сети. Реальный HTTPS: health и login — 200, проекты без cookie — 401, вход существующими данными — 200, чтение подключённого проекта после входа — 200. Новые карточки/ветки не создавались.
