## Результат

- Выбор исполнителя при создании карточки уже есть; подтверждённую карточку можно переназначить. Сервер проверяет, что ID относится к существующему сотруднику.

- Подпись счётчика уточнена: «Незавершённых задач».

## Проверки и ограничения

- Просмотрены изменения и выполнен `git diff --check`.

- Рабочая ветка локальная и не опубликована. Изменения основаны на `55e090a`.
- Подсчёт выполняется для выбранного проекта и не оценивает нагрузку в часах; планировщик и лимиты ёмкости остаются отдельной задачей.
