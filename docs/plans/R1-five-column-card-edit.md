# R1: пять колонок и безопасное редактирование карточек

5 ноября 2026. Исходная реализация Софии: upstream/main 68b2b5b. В рабочей ветке codex/r4-readable-branch-names подготовлено объединение с R3/R4 без коммита, push и развёртывания. Разрешены конфликты script.js, server.js, docs/PROJECT.md. Резервная копия исходного рабочего дерева — git stash «Safety snapshot before integrating Sofia 68b2b5b», дополнительно временный файловый снимок.

Сохранены Backlog/To Do/In Progress/Review/Done, правка названия, описания и исполнителя; одновременно сохранены clarify, интервью и поле имени ветки. Возвращён .env.example: setup снова создаёт отсутствующие конфиги и не перезаписывает личные.

Обновление подтверждённой карточки требует expectedRevision. Для прежних карточек без editRevision начальная версия 0; успешная правка увеличивает её. Проверка/запись в общей serial-очереди, устаревшее сохранение даёт 409 task_changed без изменения данных. Редактор сохраняет expectedRevision на момент открытия, блокирует повторное сохранение при конфликте и оставляет введённый текст. По явной кнопке «Загрузить свежую версию» предупреждает о сбросе правок, загружает актуальную карточку. Перенос колонки не изменяет ревизию редактируемого текста.

Проверки объединённой версии: npm run check, npm test (142/142), git diff --check и git diff --cached --check. Проверены новая установка и повторный setup, пять колонок, сохранение ветки/проекта при правке, ревизия после перезапуска, отказ устаревшего PATCH и запрет чужого Origin. В настоящем браузере две вкладки открыли одну карточку: первая сохранила название, вторая получила конфликт без потери своего текста, затем явно загрузила сохранённую версию. UI-проверка использовала изолированное хранилище и GitHub-заглушку, публичные данные не менялись.

Незавершённых конфликтов нет. После поручения пользователя сохранить и опубликовать рабочую ветку подготовлен финальный коммит объединения. Перед публикацией оформить логичные коммиты/PR, учтя зависимость R4 от R3 и входящий коммит Софии. Сохранённый stash пока не удалён для восстановления прежнего рабочего состояния.
