# Управление профилями сотрудников: API

- Дата: 15 ноября 2026.
- Ветка: `r2-employee-management-api`.
- База: `karinalien/main` (`55e090a`).
- Объём по плану команды: хранение и API Софии. Интерфейс редактирования профилей остаётся отдельной задачей.

## Результат

- `POST /api/employees` создаёт профиль со случайным UUID.
- `PATCH /api/employees/:id` частично меняет профиль; ID, привязка пользователя и служебные поля не редактируются.
- Проверяются имя, должность, тип исполнителя, список навыков, доступные часы и адрес аватара. Значения сохраняются в существующей SQLite-таблице `employees`; миграция схемы не нужна.
- `avatar_url` принимает HTTPS-ссылку или локальный путь, чтобы UI карточек мог безопасно отобразить установленный аватар.
