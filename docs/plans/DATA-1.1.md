## Результат и границы

Создана пустая SQLite-база с версионной схемой, ограничениями целостности и повторяемым скриптом инициализации. Добавлены `projects` для нескольких репозиториев и `users` отдельно от сотрудников. Подключение к API/UI, перенос JSON, авторизация пользователей, webhook и CRUD не входят в этот этап по запросу пользователя «пока просто создай».

## Контекст и решения

Используются Node.js 24.14.1 и встроенный `node:sqlite`; ORM и зависимости не добавляются. Все внутренние ключи — TEXT для сохранения UUID работающих задач/проектов. Capacity определена как целое число часов на спринт. Настройки GitHub и секреты не хранятся в БД. Рабочее JSON-хранилище остаётся действующим.

Файлы: `db/migrations/001-initial.sql`, `lib/database.js`, `scripts/db-init.js`, `test/database.test.js`, `docs/DATABASE.md`. Локальная `.data/task-manager.sqlite` уже исключена из Git правилом `.data/`.
