# Аватар исполнителя в карточке

- Дата: 15 ноября 2026.
- Ветка: `card-assignee-avatar`.
- База: `karinalien/main` (`55e090a`).

## Результат

- В каждой карточке показываются назначенный сотрудник и его `avatar_url`.
- Если ссылка отсутствует или изображение не загрузилось, отображаются инициалы; если исполнитель не назначен — прочерк и подпись.
- Для HTTPS-изображений CSP разрешает загрузку только картинок. Запрос отправляется без Referer.
- Поле `avatar_url` уже есть в SQLite и GET API. Ветка `r2-employee-management-api` добавляет способ менять его через API; без неё значение можно показывать, если оно уже записано в базе.

## Проверки и ограничения

- Просмотрены изменения и выполнен `git diff --check`.
- Автоматические тесты и ручная проверка интерфейса не запускались.
- Рабочая ветка локальная и не опубликована. Изменения основаны на `55e090a`.
