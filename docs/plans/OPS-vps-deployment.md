## Публичный этап, 1 ноября 2026

Разрешён пользователем в чате. Подготовлены поддержка точного HTTPS DuckDNS в SHARED_ORIGIN, общий лимит 30 входов/минуту (включая успешные; при исчерпании вход временно недоступен всем), один активный вызов модели без очереди. Лимиты в памяти процесса; перезапуск их сбрасывает. Это базовая защита учебной доски, не полноценная защита от DDoS. Cookies Secure/HttpOnly/SameSite=Strict и проверка Host/Origin сохранены. Не доверяем IP-заголовкам клиента.

scripts/vps/public-https.sh проверяет длину пароля (12+), делает backup, устанавливает Caddy из Ubuntu apt, меняет только три файла приложения и SHARED_ORIGIN, проверяет конфиг и закрытый API до открытия TCP 80/443. При ошибке после начала замены откатывает файлы/env, закрывает веб-порты и останавливает Caddy. Скрипт одноразовый, отказывается перезаписывать существующий Caddyfile. Установленные пакеты не удаляются при откате. HTTPS-сертификат выпускается Caddy автоматически; DuckDNS token для статического IP не хранится в приложении.

Проверки подготовленной версии: npm run check — 35 JS, npm test — 108/108, bash -n и git diff --check — успешно. Применение публичного этапа и внешний вход ещё не проверены; требуется один sudo-запуск пользователем. До него рабочий VPS остаётся на прежней закрытой версии 12592ab.
