# UI: отдельная страница проектов

Статус: завершено.
Владелец: Codex. Review: команда проекта.
Ветка: `codex/r4-create-task-branch` (продолжение текущих изменений).
Требования: запрос пользователя о переносе управления репозиторием.

## Результат и границы

Настройки репозиториев доступны на отдельной странице «Проекты». На доске остаются текущий проект и компактные карточки задач. Репозиторий, ветка, статус, ошибки, критерии и шаги показаны только в окне задачи. API, хранение и права GitHub не меняются.

## Контекст и решения

`projects.html` и `projects.js` содержат выбор проекта, каталог App, подключение по ссылке, базовую ветку и отключение. `index.html` и `script.js` отвечают за доску. Выбор передаётся через sessionStorage и явный projectId в ссылке на доску; URL проверяется по серверному списку проектов. Сервер раздаёт новые файлы через прежний явный список ресурсов.

## Критерии приёмки

- [x] Настройки подключения отсутствуют на доске, доступны через навигацию.
- [x] Переход на доску открывает выбранный проект.
- [x] Неизвестный projectId не направляет запросы на произвольный репозиторий.
- [x] Узкий экран не создаёт горизонтальную прокрутку страницы проектов.
