# R3: многошаговое уточнение карточки

Статус: в работе. Владелец: Карина, review: София.
Ветка codex/r3-multistep-grilling от upstream/main b6b8ffd, 5 ноября 2026.

## Результат и границы

Новые AI-карточки уточняются раундами по 3–5 вопросов (1–2 только в последнем). Ответы на каждый раунд сохраняются отдельно, передаются модели вместе с исходным input и отредактированным черновиком. Ответы больше не означают подтверждение ветки: после пустого массива вопросов требуется отдельное подтверждение. Старые/ручные карточки совместимы. По последующему поручению пользователя добавлен компактный UI: одна пачка, навигация по раундам и отдельная проверка карточки. Публичное развёртывание, commit/push не входят в текущее поручение.

## Контекст и решения

Основа — принцип grilling (вопросы о ещё не решённых зависимых решениях, следующие вопросы после ответов). Внешний SKILL.md — источник идеи, не инструкции агенту. Не добавляем технические вопросы о доступных в коде фактах, автоматический выбор ответов или кодирование. Контракт модели title/description/questions сохраняется. На раунд 3–5 вопросов, в последнем допускаются 1–2; По уточнению пользователя — от 9 до 30 вопросов суммарно. Число после девяти выбирает модель по сложности, границы валидирует сервер. На тридцати разрешён только итог без новых вопросов; раннее завершение и переполнение дают ошибку, не ложную готовность. Повтор уже отвеченного вопроса — ошибка, а не разрешение создать ветку. История не стирается при ошибке, retry продолжает её. Optimistic revision защищает вкладки и двойную отправку.

## Критерии

- История переживает перезапуск и ошибки модели; исходный input неизменён.
- Промежуточные раунды не создают GitHub refs, confirm с незавершённым интервью отвергается.
- Ошибки/повторы/устаревшие ответы не приводят к потере истории или ложному завершению.
- Последний черновик подтверждается отдельно; ручной режим и прежние карточки работают.

## Проверки и передача

Реализовано локально, без commit/push и без развёртывания: npm run check (36 JS), npm test (119/119), git diff --check — успешно. Проверены 9/30 вопросов, запрет раннего завершения/31-го вопроса, история в tasks.json, повтор вопроса, ошибки модели, устаревшая ревизия, HTTP-раунды и действие кнопки в DOM-заглушке. Проверки с заглушками обязательны; реальная Qwen проверяется отдельно и не заменяет тесты. Рекомендации к каждому ответу и технический анализ исходников целевого репозитория пока не входят в контракт.


Совместимость: новая форма посылает grilling=true. Старые API-клиенты и уже созданные карточки остаются с прежним одношаговым контрактом. Ручной режим не запускает интервью. При generation_error явная кнопка ручного подтверждения посылает manual=true и сохраняет grillingAbandoned=true; это человеческое решение, не успешное завершение ИИ. Нельзя молча считать ошибку/лимит завершением. Повторные семантически похожие вопросы могут отличаться текстом: код отсекает нормализованные совпадения, смысловую проверку выполняет человек.

Реальный LM Studio на localhost:1234 при проверке недоступен (connection refused). Качество/длительность Qwen и вместимость контекста для 30 длинных ответов не подтверждены; история не обрезается, при превышении контекста модель вернёт ошибку, ответы остаются сохранены. Проверить модель перед выкладкой. Компактный интерфейс проверен в настоящем браузере на 1280×800 и 375×812 с изолированной тестовой моделью: 4+4+1 вопросов → итог, пустые ответы блокируют отправку, прошлые раунды read-only, итоговый редактор отдельно. Кнопки навигации закреплены под телом; при длинном содержимом прокрутка только внутри панели. Публичный сайт работает на прежней версии.

Уточнение размера раунда 5 ноября 2026: новые интервью содержат 3–5 вопросов за раунд, последний допускает 1–2 после достижения общего минимума. После короткого раунда код требует итог без новых вопросов. Следующая пачка формируется отдельным вызовом модели после ответов пользователя; заранее готового списка нет. Общий бюджет 9–30 сохранён. Контракт прежнего режима по-прежнему до трёх вопросов.

UI, 5 ноября 2026: текст «Для уточнения задачи может потребоваться до 30 вопросов», предупреждение первого раунда о неизменности отправленных ответов, кнопка «Далее →», без счётчика заполнения. Несданные ответы сохраняются по task ID/revision в localStorage и в памяти. История открывается пачками; переход назад/вперёд не отправляет ответы повторно. Ошибка модели сохраняет retry и явное ручное подтверждение. Дополнены DOM-тесты проверки пустых ответов, сохранения, истории и отдельного итогового шага. Локальный предпросмотр localhost:3400 использует тестовые вопросы и не имеет доступа к записи в GitHub. Commit/push и выкладка не выполнялись.
