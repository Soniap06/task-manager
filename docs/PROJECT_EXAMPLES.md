# Рабочие примеры для Task Manager

## Текущий пример: трекер привычек

Выбран пользователем 20 октября 2026 года. Отдельный публичный репозиторий: [karinalien/habit-tracker](https://github.com/karinalien/habit-tracker). Исходники Task Manager в него не переносятся.

Подготовлен стартовый проект Node.js 24 без зависимостей: библиотека привычек, ежедневные отметки, консольная демонстрация и 3 теста. Пока данные примера живут в памяти. Это основа для задач, а не законченный сайт трекера.

Примеры задач: удаление привычки с обработкой неизвестного ID; подсчёт серии; сохранение в JSON; веб-интерфейс; документация API. Через Task Manager генерируется ТЗ и ветка, но сам код задачи автоматически не реализуется.

## Будущий пример: сайт театра

Оставлен по пожеланию пользователя на следующий этап. Сейчас репозиторий и сайт не создаются. Возможные задачи позднее: афиша, страницы спектаклей, фильтр по датам, форма обращения. Для проверки переключения проектов сейчас достаточно заглушек двух репозиториев в автоматических тестах.
