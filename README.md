# Task Manager

Минимальный интерфейс интерактивной канбан-доски для курсового проекта.

## Реализовано

- создание карточки задачи;
- колонки To Do, In Progress и Review;
- перемещение карточек кнопками ← и →;
- адаптивное отображение для небольших экранов;
- запуск без backend и дополнительных библиотек.

## Запуск

1. Создайте локальный файл `ai-api.js` (он уже добавлен в `.gitignore`) со следующим содержимым:

```javascript
window.AI_API_CONFIG = {
    provider: "lm-studio",
    endpoint: "http://127.0.0.1:3000/api/ai",
    apiKey: "",
    model: "qwen/qwen3.5-9b"
};
```

2. Запустите локальный proxy-сервер из папки проекта:

```bash
node server.js
```

3. Откройте в браузере адрес `http://127.0.0.1:3000`, а не файл `index.html`.

В LM Studio перед запуском приложения загрузите модель и запустите локальный сервер. В вашем случае используются модель `qwen/qwen3.5-9b` и адрес `http://127.0.0.1:1234`. Файл `server.js` нужен как proxy, чтобы браузер не блокировал запрос из-за CORS.

Интеграция использует OpenAI-совместимый API LM Studio. Для OpenAI можно заменить `endpoint` на `https://api.openai.com/v1/chat/completions`, указать ключ и выбрать модель, например `gpt-4o-mini`.

> Локальный LM Studio API не требует ключа. Для опубликованного приложения нельзя хранить ключ OpenAI в браузерном коде: нужен backend-прокси, который хранит ключ в переменных окружения.

## GitHub Pages

Для публикации:
1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите Deploy from a branch.
3. Branch: `main`.
4. Folder: `/ (root)`.
5. Нажмите Save.

После публикации GitHub выдаст ссылку на сайт.
